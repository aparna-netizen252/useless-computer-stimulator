Project Description

Useless Computer Simulator is an interactive simulated desktop operating system where every familiar computer action intentionally fails, wastes time, or responds with sarcasm.

Built with React, Tailwind CSS, Lucide icons, and the Web Audio API, it provides a surprisingly realistic desktop experience with absolutely no productivity involved.

The Problem (that doesn't exist)

People are becoming dangerously productive.

Computers are being used for work, studying, coding, communication, and other suspiciously useful activities. There was clearly a need for a computer that does the exact opposite.

The problem: There aren't enough computers that waste your time while convincing you that something useful is about to happen.

The Solution (that nobody asked for)

Introducing the Useless Computer Simulator — a fully interactive desktop that looks productive but actively prevents productivity.

Click Print → wastes ink.

Open My Files → "Better luck next time."

Check the Network → "The network isn't networking."

Open Settings → "Fix it yourself zone."

Click Start → "Click here and hope."

Basically, we built a computer whose primary function is to disappoint you.

Implementation

For Software:

Installation

Clone the repository:

git clone <your-repository-url>
cd <project-folder>

Install dependencies:

npm install

Run

Start the development server:

npm run dev

Open the local URL displayed by Vite in your browser.

Alternative

If using a static version of the project, simply open:

index.html

in a modern web browser.

You can also use:

python -m http.server 8080

Then open:

http://localhost:8080/

Core Useless Interactions

The simulator contains 10 guaranteed useless core interactions:

1. 🖨️ Print
   
   - Displays "Wasting some ink..."
   - Shows animated progress.
   - Includes mechanical printer sound effects.
   - Produces absolutely no printed document.

2. 📄 My Files
   
   - Opens a useless response:
   - "Better luck next time."

3. 📁 Important Stuff
   
   - Shakes dramatically when clicked.
   - Refuses to open.
   - Displays "Better luck next time."

4. 🗑️ Recycle Bin
   
   - Displays:
   - "Here is the place where stuff goes to disappear."
   - Contains useless files such as:
     - "Motivation.dll" — 0 KB
     - "Productivity.docx" — 0 KB

5. 📊 Taskbar
   
   - Reports:
   - "I'm the multi-tasking disaster bar."
   - Productive tasks running: 0

6. 🚀 Start Menu
   
   - Displays:
   - "Click here and hope."

7. ⚙️ Settings
   
   - Provides completely non-functional settings.
   - Includes useless sliders and humorous toggles.
   - Clearly labelled:
   - "Fix it yourself zone."

8. 🔍 Search
   
   - Displays:
   - "Where is it?"
   - Returns useless results such as:
     - "We looked everywhere."
     - "Definitely not here."

9. 🔔 Notifications
   
   - Displays:
   - "Attention please, there is no messages for you."

10. 📶 Network
    
    - Displays:
    - "The network isn't networking."
    - Signal status:
    - Emotionally unavailable

Sound Engine

The project includes a browser-based sound engine using the Web Audio API.

It generates:

- 🖱️ Click sounds
- 🔔 Notification chimes
- ⚠️ Error beeps
- 🖨️ Printer sounds
- 🔊 Interaction feedback

A taskbar mute control is also included for users who have had enough of the computer's nonsense.
